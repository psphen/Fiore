## When to Use

- Working on any file inside `src/app/features/dashboard/category/`
- Generating category form, list, or service
- Dealing with category-product relationships

---

## Domain Context

Categories organize the product catalog. Customers browse by category on the public landing page. The API uses the escuelajs.co backend — the real Category model from the API is simpler than what the full feature spec describes.

---

## Model (actual — matches live API)

```typescript
// src/app/features/dashboard/category/models/category.model.ts

export interface Category {
  id: number;
  name: string;
  slug: string;
  image: string;      // URL string — required by API
}

export type CategoryDTO = Omit<Category, 'id' | 'slug'>;
```

> NOTE: `parentId`, `icon`, `description`, `isActive` are NOT in the live API. Do not add them to the model unless the backend is extended.

## API Endpoints

Base URL: `/api/v1/categories`

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/categories` | List all categories |
| GET | `/api/v1/categories/:id` | Get by ID |
| GET | `/api/v1/categories/:id/products` | Products in this category |
| POST | `/api/v1/categories` | Create (send `name` + `image` URL) |
| PUT | `/api/v1/categories/:id` | Update |

> The delete endpoint is NOT exposed by the external API — do not implement delete.

---

## Form Fields & Validation

| Field | Type | Rules | Error message |
|-------|------|-------|---------------|
| `name` | text | required, 2–50 chars | "El nombre es requerido (2-50 caracteres)" |
| `image` | text / upload | required, valid URL | "La imagen es requerida" |

`slug` is auto-generated by the server — never include in DTOs.

## Category-Product Relationship

- The `ProductsModal` shared component (`shared/ui/products-modal`) opens when clicking "Ver Productos" on a category row
- It uses `getProductsByCategory(categoryId)` to load the products
- Import it as: `import { ProductsModal } from '../../../../shared/ui/products-modal/products-modal'`
- Open it via `MatDialog`: `this.dialog.open(ProductsModal, { data: { products } })`

---

## Business Rules

- Category names should be unique — use `checkCategory(name)` before creating
- An image URL is mandatory — use the files service or accept a direct URL
- Deleting a category from the UI is disabled (API restriction)
- The list page shows a search filter by name (client-side)
- Clicking "Ver Productos" opens the products modal for that category
